# 3-5 Minute Demo Script

## 1. Problem
QA teams spend hours reading Jira stories and creating first-draft test assets manually. This delays sprint readiness and creates inconsistent test coverage.

## 2. Users
The users are QA Engineers, Automation Engineers, QA Leads, and Scrum Teams.

## 3. Solution
QA Copilot converts a Jira story into a complete QA package including test scenarios, negative tests, API coverage, risk assessment, requirement gaps, and Playwright automation skeleton.

## 4. Demo
Paste the password reset story and click Generate QA Package. Show the generated output.

## 5. AI Role
AI acts as multiple QA agents: Requirement Analyzer, Gap Detector, Test Designer, API Coverage Agent, Automation Coach, and Risk Reviewer.

## 6. Impact
Manual preparation can take 3-4 hours per story. QA Copilot creates the first draft in seconds, saving up to 80-90% of initial preparation effort.
